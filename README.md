# Hospital-Management-Html
A decent Hospital Management System which is created using Html, css and Bootstrap.

# Features
Responsive design using Bootstrap.

Clean and modern user interface.

Core sections include:

Home Page: Overview of the hospital’s services.

About Page: Information about the hospital.

Departments: Details about different hospital departments.

Doctors: Profiles of doctors with their specialties.

Contact Page: A form for inquiries or appointments.


# Technologies Used

HTML5: For structuring the web pages.

CSS3: For styling and layout.

Bootstrap: For responsive design and pre-built component
